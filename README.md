This is a collection of any screen maps and other visual resources I've either made or found from club worlds I've visited. All resources for lights are in a different repository. There is a server I am a part of that has a world sharing section, and this allows me to send updates to worlds I map without having to post up new files every time, I just update this repository.

If you find issues with any of the files or have your own fixes, please create an issue report or a pull request. I will review them as I have the time.

Every folder here should be an individual world that I've mapped. If the world has original files for a screen map, then I will provide those. If they only provide screen map images, I will usually create my own as well. I use [SliceMap](https://skoetting.net/SliceMap/) to create my screen maps, which supports saving and loading the project from a JSON file, which is also provided.

I also provide Resolume Arena Advanced Output XMLs and frames for each screen (output as a 12 pixel border) generated using SliceMap and put in a ZIP archive.
